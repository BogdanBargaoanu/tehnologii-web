Spinner de încărcare

Conținut pagină

Acesta este un exemplu de spinner de încărcare creat doar cu HTML și CSS. Spinner-ul de mai sus se va roti continuu pentru a indica procesul de încărcare.

Spinner-ul este creat folosind următoarele tehnici:

  • Un element div stilizat ca un cerc
  • Proprietatea border pentru a crea marginile cercului
  • Proprietatea border-radius pentru a obține forma circulară
  • Animație CSS definită cu @keyframes pentru a crea rotația
